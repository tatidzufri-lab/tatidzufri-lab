# Tetiana Dziubas

AI automation engineer. I build Telegram bots, RAG assistants and LLM agents that take routine work off small teams, and I show how I build them.

Case studies, live demos and contact: [tatidzufri.com/en](https://tatidzufri.com/en/).

## What I do

Telegram bots with language models, knowledge base assistants, multi-agent systems, website scraping and monitoring, document and report generation in PDF, Word and PowerPoint, automating work with reviews and content.

For nine years I co-owned a family retail business, so I know an owner's problems from the inside: sales, negotiations, accounting, never enough hands. That's where every project starts for me; the technology comes after. I build with Claude Code and Cursor.

## Right now

I'm building a multi-agent content factory in Claude Code: seven agents prepare a week of posts, from strategy and fact-checking to images, and nothing goes out to Telegram or LinkedIn until I approve it from my phone.

## Stack

- **Languages and backend:** Python, SQL, FastAPI, Flask, REST, webhooks.
- **Models:** OpenAI, DeepSeek, GigaChat, Yandex Cloud, Cloud.ru.
- **RAG and data:** ChromaDB, Qdrant, LangChain, RAGAS, Pandas, Matplotlib.
- **Bots:** Telegram Bot API, aiogram, python-telegram-bot.
- **Documents:** WeasyPrint, python-docx, python-pptx, Jinja2.
- **Scraping:** Requests, httpx, BeautifulSoup4, Selenium.
- **Infrastructure:** Docker Compose, my own VPS, n8n, Git.
